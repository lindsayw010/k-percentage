# Project Title

MLB Strikeout Percentage Model

## Description

This repo contains Python code for a Bayesian Inference model to predict the strikeout percentage of MLB pitchers. The training dataset contains pitch data from 2021 through 2025. The goal is to estimate the strrikeout percentage of pitchers in the MLB for the 2025 season, as well as begin to explore how this model can be interpolated to estimate k percentages into the future.   

## Getting Started

### Dependencies

* Jupyter Notebook
* Python 3.11 or higher
   * numpy
   * pandas as pd
   * scikit-learn
   * matplotlib
   * pymc
   * arviz

### Installing

* Download `src/k_percentage.ipynb` and run in virtual environment containing the dependencies listed above.

### Executing program

* Run each cell in the notebook in order, or execute entire notebook.
